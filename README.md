## Built around production, not demos

Nex tools are designed around the work that happens after the prototype:

```text
Less repetitive setup
        ↓
Clearer editor workflows
        ↓
Faster iteration
        ↓
More time spent building the actual game
```

The goal is not to replace Unity. It is to make Unity feel more deliberate, connected, and efficient.

<br />

## Principles

| | Principle | What it means |
|---:|---|---|
| 01 | **Editor-native** | Tools should feel like a natural extension of Unity. |
| 02 | **Focused by default** | Every feature must solve a real production problem. |
| 03 | **Modular architecture** | Projects should adopt only what they actually need. |
| 04 | **Fast iteration** | Good tooling should shorten the distance between idea and result. |
| 05 | **Production-minded** | Maintainability matters as much as first-run convenience. |
